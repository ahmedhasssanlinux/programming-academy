# CodeVerse Learning Platform

This project is a complete static educational website for teaching programming languages using HTML, CSS, and JavaScript.

## Features
- Responsive landing page
- Multi-language programming sections
- Learning paths and roadmap
- Tutorial tabs with lesson content
- FAQ and CTA sections
- Ready for deployment on GitHub Pages / Netlify / Vercel

## Run locally
Open `index.html` directly in the browser, or use a local static server:

```bash
python3 -m http.server 8000
```
Then visit: http://localhost:8000

## Deployment
You can deploy this static site to:
- GitHub Pages
- Netlify
- Vercel
- Firebase Hosting

## Project structure
- `index.html` - main page
- `styles.css` - all styling
- `script.js` - interactivity

## Languages included
HTML, CSS, JavaScript, TypeScript, Python, PHP, Node.js, Java, C++, C#, Rust, SQL
